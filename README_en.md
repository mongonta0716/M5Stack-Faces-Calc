# M5Stack-Faces-Calc

[日本語](README.md) | English

 Calculator for M5Stack Faces with Calculator Module.

# Faces Calculator3 Support
 [Faces Calculator3](https://docs.m5stack.com/en/faces/Faces_Calculator3) is supported.

- Tested on M5Stack Basic + Faces Calculator3 (firmware V03).
- Key input is read by polling I2C (address 0x08, `M5.In_I2C` of M5Unified). The INT pin is not used.
- Calculator3 long press is supported.
  - Long press A key: BackSpace
  - Long press = key: Calc Execute

# Usage
 Build and upload with PlatformIO (see "Compile" below).

 To launch it from [M5Stack LovyanLauncher](https://github.com/lovyan03/M5Stack_LovyanLauncher), copy `.pio/build/m5stack-basic/firmware.bin` generated by the build to the microSD card as `Faces_Calc.bin`. Hold button A while booting to return to the launcher (menu.bin).

 ## Operation

- AC: All Clear
- M: Mode Change (Calc Mode ⇔ Scroll Mode)

 ### Calc Mode
 Enter an expression at the prompt and press "=" to calculate it. The expression and the answer are copied to the table area.
- \` (+/-) : BackSpace (or long press A key)
- % : Clear Prompt Line
- = : Calc Execute (or long press)

 ### Scroll Mode
 Move with the 2, 4, 6 and 8 keys. Press 5 to copy the line surrounded by the red frame to the prompt and edit it.

 # Requirement

 The following libraries are required to compile. Install M5Unified and SD-Updater from the Arduino IDE Library Manager.
 For TinyExpr, copy tinyexpr.h and tinyexpr.c into the same folder as Faces_Calc.ino. (Not needed for PlatformIO.)

 - [M5Unified](https://github.com/m5stack/M5Unified)
 - [M5Stack-SD-Updater](https://github.com/tobozo/M5Stack-SD-Updater)
 - [TinyExpr](https://github.com/codeplea/tinyexpr)

# Features and Limitations
Up to 99 history entries are saved. (They are kept after power off or reset.)
Because of the number of display digits, answers outside the range 999,999,999,999 to -99,999,999,999 cause an error.

## Compile
### PlatformIO
You can build with `platformio.ini` in the repository root. Libraries are fetched automatically, and TinyExpr is bundled in `lib/tinyexpr`.

```
pio run                          # Build (M5Stack Basic)
pio run -t upload                # Upload
```

### Arduino IDE
With the Arduino IDE, compilation fails unless the compiler warnings setting is "None". This will be fixed in the future.

# If it hangs because of corrupted data
Temporary files are stored in SPIFFS. If they get corrupted, the app hangs after startup.
In that case, hold button B (the middle button) of the M5Stack Core while booting to clear them.
